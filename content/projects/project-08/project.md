A flock pulled out of a soft gray field, each bird reduced to a few decisive pixels.

This project is a media-integration example. The gallery places the local
bitmap beside a custom vector flight study and a PDF reference. The SVG stays
inside the project folder, so students can replace it with their own artwork
without relying on a generic external import.
