A flock pulled out of a soft gray field, each bird reduced to a few decisive pixels.

This project is a media-integration example. The gallery places a local bitmap
beside an external SVG from Wikimedia Commons and an external PDF reference.
The sources remain URLs in the markdown, so students can replace them with
their own public media without changing the viewer.
