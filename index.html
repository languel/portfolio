PROJECT 01 · 2026

Project 1 — The Monolith

ARTIST STATEMENT

An inquiry into brutalist verticality and 4×4 Bayer matrix ordered dithering. An obsidian obelisk anchors the composition against a sparse stellar field and an exponential perspective plane, bisected by a luminescent core signal line.

SPECIFICATIONS

MEDIUM Procedural Shaders
RESOLUTION 512 × 512 px (Native 128×128)
PALETTE 8-Level Bayer Grayscale
PIPELINE Python Bitmap Engine / GLSL

TECHNICAL TAGS

#Bayer Dither #Procedural #Brutalism

ABOUT // ARTIST DOSSIER

LANGUEL // DIGITAL ARTIST
